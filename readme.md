# Zig Text Inspector

A small command-line text analysis program written in Zig.

This project was created while learning Zig through Ziglings
and the Introduction to Zig tutorial.

## Goals

The purpose of this project is to practice:

- Zig strings
- arrays and slices
- functions
- loops
- const and var
- primitive types
- the Zig standard library
- basic project structure

## Features

- Display text length
- Count spaces
- Count vowels
- Count words
- Detect prefixes and suffixes
- Count occurrences of a word
- Inspect raw bytes
- Work with slices
